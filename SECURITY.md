# Security

Report a vulnerability by email to contact@blockhash.xyz.
Please send it privately, and not as a public issue or pull request.

Say what it affects: the SDK, the MCP server or the example bot, and the version.
Say how to reproduce it, and what it lets someone do.
A vulnerability in Mancer's contracts or its API goes to the same address.

Please give us the time to fix it before you tell anyone else.
